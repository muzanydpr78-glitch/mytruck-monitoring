# Security Policy

## Reporting a vulnerability
Jangan melaporkan rahasia atau data pribadi melalui issue publik. Untuk penggunaan internal, laporkan secara privat kepada pemilik repository atau tim keamanan organisasi. Repository ini belum mencantumkan alamat pelaporan karena belum ditentukan.

## Scope and limitations
Kode ini adalah prototipe dan belum menjalani audit keamanan. Jangan gunakan dengan data produksi sebelum autentikasi, manajemen sesi, kontrol akses server-side, logging, dan pengelolaan rahasia ditinjau dan diuji.
